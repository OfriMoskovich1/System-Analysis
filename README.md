Systems Analysis and Design: Restaurant Management

Overview

This repository contains a comprehensive Systems Analysis and Design project focused on a restaurant branch (BBB, Ahi Eilat). The project aims to analyze the current organizational and operational processes, identify bottlenecks, and propose an optimized, technology-driven future state.

Project Scope

The analysis focuses on two main operational processes:  

1. Employee Scheduling and Shift Management: Transitioning from manual, intuition-based scheduling to a data-driven, automated system.  

2. Order Management and Kitchen Synchronization: Upgrading from a disconnected, paper-based ticketing system to an integrated digital workflow using Kitchen Display Systems (KDS) and customer self-service tablets.  

Methodologies and Tools

The project utilizes various systems analysis methodologies, including:

 Information Gathering: Triangulation through semi-structured interviews, event-based observations, and electronic customer surveys.  

 Process Modeling: Detailed BPMN (Business Process Model and Notation) diagrams illustrating both AS-IS (current) and TO-BE (future) states.  

 Data Modeling: An Entity-Relationship Diagram (ERD) defining the core data structures and relationships.  

 Requirements Engineering: A comprehensive list of functional and non-functional requirements.  

 Alternative Evaluation: A detailed cost-benefit analysis of various technological solutions, leading to a recommended implementation plan.  

 UI/UX Design: User personas, empathy maps, and low-fidelity wireframes demonstrating the proposed user interfaces.
